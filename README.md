# EDA: AI History Timeline

Exploratory data analysis (NIST EDA style) of the Chronicle AI history dataset: 78 milestones, 21 columns.

- `EDA_ai_history_timeline.ipynb` - executed notebook: data check, histograms and bar charts with summary statistics and outliers, one side-by-side box plot, scatter-plot matrix, categorical vs categorical and categorical vs numerical views, conclusions
- `data/ai-history-events.csv` - the dataset (https://epoch.founden.co/data)
- `build_notebook.py`, `conclusions.md` - regenerate the notebook

Data credit: Chronicle AI history dataset (https://epoch.founden.co/data), CC BY 4.0.

Run: `pip install -r requirements.txt && jupyter notebook`
